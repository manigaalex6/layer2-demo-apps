# Layer 2 Demo Apps

This repository is intended to host materials for the practical training labs for the Layer 2 AI Initiative.

The Project Board can be found here: [Layer 2 Board](https://github.com/orgs/msggroup-AI-Labs/projects/1) 

## Structure

- [FullStack Spring and Angular App](fullstack-onlineshop)


## Contributing

- All changes must go through a PR to the `main` branch.
- Branch naming convention: `feat/<task_id>-<short-desc>`.
- Add new content under the respective application folder (e.g., `fullstack-onlineshop/`).

## Getting Started

- Ensure you have the appropriate access rights to the repository, either via an SSH key or a Git access token.
- Clone the repository using the git clone command.
